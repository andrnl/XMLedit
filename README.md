# XMLedit

Программа для просмотра и редактирования XML-файлов электронных документов (например, электронное поручение экспедитору в формате Diadoc).

## Возможности

- **Удобное отображение** XML-данных в виде дерева разделов с русскими подписями.
- **Редактирование** любых значений (атрибуты и текстовое содержимое элементов).
- **Сохранение** изменений обратно в XML-файл в том же формате.
- **Универсальность** — корректно отображает любую структуру XML (дерево строится автоматически).
- **Автоматический перевод** неизвестных тегов и атрибутов (разбиение CamelCase-имён на слова).
- **Поддержка повторяющихся элементов** (нумерация одинаковых разделов).

## Файлы

- `poruchenie_editor.py` — исходный код программы (Python + Tkinter).
- `PoruchenieEditor.exe` — готовый исполняемый модуль (не требует установленного Python).
- `81-70342.xml` — пример файла электронного поручения экспедитору.

## Запуск

### Исполняемый модуль (рекомендуется)

Просто дважды кликните по файлу `PoruchenieEditor.exe`. Программа автоматически откроет файл `81-70342.xml`.

### Из исходного кода

```bash
python poruchenie_editor.py
```

## Использование

1. Слева в дереве выберите раздел документа (Грузоотправитель, Грузополучатель, Груз, Адреса, Экспедитор, Договор и т.д.).
2. Справа отредактируйте нужные поля.
3. Нажмите «Применить изменения раздела» или «Сохранить» для записи изменений в файл.

Через кнопку «Открыть файл…» можно загрузить любой другой XML-файл.

## Сборка исполняемого модуля

Для пересборки exe-файла используется PyInstaller:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "PoruchenieEditor" poruchenie_editor.py
```
