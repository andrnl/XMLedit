# XMLedit

Программа для просмотра и редактирования XML-файлов электронных документов (например, электронное поручение экспедитору в формате Diadoc).

Интерфейс выполнен в стиле онлайн-валидатора XML Диадок (CheckXML): фирменный синий хедер, кнопки «Загрузить файл...», статусная панель с результатами проверки файла.

## Возможности

- **Удобное отображение** XML-данных в виде дерева разделов с русскими подписями.
- **Редактирование** любых значений (атрибуты и текстовое содержимое элементов).
- **Сохранение** изменений обратно в XML-файл в том же формате.
- **Универсальность** — корректно отображает любую структуру XML (дерево строится автоматически).
- **Автоматический перевод** неизвестных тегов и атрибутов (разбиение CamelCase-имён на слова).
- **Поддержка повторяющихся элементов** (нумерация одинаковых разделов).
- **Проверка файла как в валидаторе Диадок** — после загрузки показывает статус: распознан ли тип документа (по атрибуту КНД), кодировка файла, ошибки формата.

## Файлы

- `poruchenie_editor.py` — исходный код программы с деревом разделов (Python + Tkinter).
- `PoruchenieEditor.exe` — готовый исполняемый модуль с деревом разделов (не требует Python).
- `xmledit.py` — вариант **XMLedit**: все реквизиты документа видны разом на одной форме.
- `XMLedit.exe` — готовый исполняемый модуль XMLedit (не требует Python).
- `81-70342.xml` — пример файла электронного поручения экспедитору.
- `.venv/` — виртуальное окружение (Python + PyInstaller).
- `requirements.txt` — зависимости для сборки exe.

## Виртуальное окружение

Для запуска из исходного кода используйте виртуальное окружение `.venv`:

```powershell
cd C:\Users\andrnl\Documents\Python\XMLedit
.venv\Scripts\Activate.ps1          # активация (PowerShell)
# или .venv\Scripts\activate.bat    # для cmd
python poruchenie_editor.py         # запуск программы
deactivate                          # деактивация
```

Пересоздать окружение при необходимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

### Исполняемый модуль (рекомендуется)

Просто дважды кликните по файлу `PoruchenieEditor.exe` (интерфейс с деревом разделов) или `XMLedit.exe` (все реквизиты видны разом). Программа автоматически откроет файл `81-70342.xml`.

### Из исходного кода

```powershell
cd C:\Users\andrnl\Documents\Python\XMLedit
.venv\Scripts\Activate.ps1
python poruchenie_editor.py
```

## Использование

1. Слева в дереве выберите раздел документа (Грузоотправитель, Грузополучатель, Груз, Адреса, Экспедитор, Договор и т.д.).
2. Справа отредактируйте нужные поля.
3. Нажмите «Применить изменения раздела» или «Сохранить» для записи изменений в файл.

Через кнопку «Открыть файл…» можно загрузить любой другой XML-файл.

## Сборка исполняемого модуля

Для пересборки exe-файла используется PyInstaller (уже установлен в `.venv`):

```powershell
cd C:\Users\andrnl\Documents\Python\XMLedit
.venv\Scripts\Activate.ps1
pyinstaller --onefile --windowed --name "PoruchenieEditor" poruchenie_editor.py
```
