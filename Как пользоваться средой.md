# Как пользоваться виртуальной средой

## Активация

```powershell
cd C:\Users\andrnl\Documents\Python\XMLedit
.venv\Scripts\Activate.ps1      # активировать
```

После активации в начале строки появится `(.venv)`.

## Запуск программы

```powershell
python poruchenie_editor.py
```

## Пересборка exe

```powershell
pyinstaller --onefile --windowed --name "PoruchenieEditor" poruchenie_editor.py
```

## Установка зависимостей

```powershell
pip install -r requirements.txt
```

## Деактивация

```powershell
deactivate
```
